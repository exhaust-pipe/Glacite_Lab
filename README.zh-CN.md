# Glacite Lab

[打开策略优化器](https://exhaust-pipe.github.io/Glacite_Lab/) · [English](./README.md) · **简体中文**

Glacite Lab 帮助 Hypixel 空岛生存玩家决定是否开启青金石、钨、棕土或先锋尸体，以及开启时该选哪种 RNG 掉落。它根据市场报价、玩家的加成和共享 RNG 经验，估算每座矿井的长期净利润。

## 使用方法

1. 在**加成配置**中输入实际等级。每个项目均可独立调整，也可以用**无加成**或**全部满级**一次设置六项。首次打开默认为英文和满级配置，点右上角的**中文**即可切换。
2. 在**市场价格**中选择钥匙买入方式和掉落卖出方式。展开**费率与模型参数**，可调整税率、仙灵矿井占比、水晶锁定状态、先锋胸甲的未知权重，以及保底适用范围。
3. 输入当前的**共享 RNG 进度**。结果表会列出每种尸体的建议操作和开启边际价值。**开启 · 积攒经验**表示清空 RNG 选择后开启；**选取某物品**表示选好该目标后再开启。
4. 在 **RNG 策略图**中查看经验累积到什么位置需要切换操作。明细表列出含首尾的网格区间。当前操作按输入的精确经验单独计算，也能识别两个网格点之间的保底门槛。

修改设置会自动重算。切换中英文时会保留输入和求解结果。浏览器会记住语言、设置、当前经验与手动覆盖价。

## 加成与默认值

| 设置 | 范围 | 对模型的影响 |
| --- | --- | --- |
| 节约用钥（Resourceful） | 0–5 级 | 每级增加 1% 的钥匙保留概率。 |
| 亡者馈赠（Gifts from the Departed） | 0–100 级 | 每个有效等级使额外抽取一次掉落的概率增加 0.2 个百分点。 |
| 亡者宝箱（Dead Man’s Chest） | 0–50 级 | 每个有效等级使普通矿井额外生成一具尸体的概率增加 0.5 个百分点。 |
| 尸体里程碑 | 未解锁、I–VII | II、V 各增加 10 个百分点的额外尸体概率。III、VI 各增加 10 个百分点的额外抽取概率，奖励累加。 |
| 蓝奶酪哥布林煎蛋（Blue Cheese Goblin Omelette） | 开 / 关 | 已解锁的上述两项山心技能各加一级，允许超过训练等级上限。零级技能保持未解锁。 |
| 怜悯（Pity） | 0–10 级 | 每级增加 1% 的尸体 RNG 经验。 |

普通矿井固定有两具尸体，另有 50% 概率生成第三具。六项加成全满时，普通矿井期望 **2.955 具**，额外抽取概率 **40.2%**，钥匙消耗率 **95%**。全部关闭时，三项分别为 **2.5 具、0%、100%**。仙灵矿井固定只有一具先锋，默认情景占比为 8.6%。

## 价格来源

页面从 Hypixel 获取集市订单簿与 NPC 收购价。立即买入和挂卖单都取最低卖价，立即卖出和挂买单都取最高买价。拍卖行物品优先取 SkyHelper 价格，缺价时请求 Coflnet 最低一口价。拍卖行挂牌价和集市挂单价均为报价，实际成交价可能变化。

卖出收入取 NPC 收购价和市场税后价两者的较高值。集市卖出税率默认 1.125%，拍卖行估算费率默认 3%。手动输入正数会同时覆盖该物品的税前买价和卖价，清空即可恢复自动取价。

每次打开页面都会请求新报价。自动刷新开启后，页面在前台且求解器空闲时每 60 秒刷新，也可点**刷新价格**立即更新。首次打开使用带时间戳的 39 件物品参考报价，之后可在刷新期间使用浏览器已保存的报价。状态栏显示集市报价时间，并标记延迟或不可用的来源。若请求成功但某一侧没有挂单，该侧报价会清空。任何必需卖价或钥匙买价仍缺失时，求解会暂停，并在明细中标出对应物品。

## 计算模型

- 看到尸体类型后，求解器比较跳过、无目标开启、选择各适用目标后开启。四种尸体按每座矿井的期望遭遇数加权。**开启边际价值**包括未来 RNG 经验的价值变化。**基础净利**等于未选 RNG 目标时的掉落期望减去钥匙成本。
- 青金石、钨 / 棕土、先锋的基础抽取次数分别在 3–6、4–7、5–8 之间均匀分布。额外抽取概率会混合原分布和多抽一次的分布。怜悯按比例增加经验，四种尸体的基础经验依次为 500、2,500、2,500、25,000。
- 选中物品的掉落包权重乘以 `1 + min(2 × 已存经验 / 所需经验, 2)`，再对奖池归一化，并按实际堆叠数量计价。冻伤染料独立替换一次普通抽取，模型以赔率缩放近似其 RNG 加成。未达保底时自然命中目标，假定整具尸体结算后经验清零。保底占用一次抽取、发放一件目标物品，扣除门槛经验后再获得本次开启经验。
- 后台 Web Worker 先用较粗的网格估计初值，再以 **2,500 XP** 为步长求解至 **5,050,000 XP**，用线性插值计算中间状态。利润区间来自最终的贝尔曼残差，宽度反映离散模型的数值误差。**最高保底兑换率**是净卖价除以保底经验，实际最优目标还取决于当前经验和尸体类型。
- 普通矿井的尸体比例为 50% 青金石、25% 钨、25% 棕土。已锁定的水晶从奖池移除，未锁定的水晶保留权重并计为零金币。钨 / 棕土奖池按条目求和，锁定时总权重为 6,440，未锁定时为 6,640。先锋胸甲掉落权重未知，默认设为零。保底默认只适用于含目标的奖池，也可切换到实验性的任意尸体模式。
- 金币目标衡量尸体掉落与钥匙成本。路程时间、粉末估值、一次性里程碑奖励、实际成交滑点与资金限制未纳入模型。

## 本地运行

网站使用静态 HTML、CSS 和 JavaScript 模块。在仓库根目录启动 HTTP 服务后，打开 [localhost:8000](http://localhost:8000/)。

```sh
python3 -m http.server 8000
```

使用 Node.js 18 或更高版本运行回归测试。网页与测试均无 npm 依赖。

```sh
node --test
```

GitHub Pages 从 `main` 分支根目录发布。`js/data.js` 保存掉落包与 RNG 目标，`js/model.js` 实现求解器，`js/market.js` 处理报价，`js/i18n.js` 保存界面译文。
